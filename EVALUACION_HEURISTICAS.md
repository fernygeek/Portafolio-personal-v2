# Evaluación de las diez heurísticas de Nielsen

Fecha: **18 de octubre de 2026**. Alcance: implementación local del portafolio de Fernanda Rueda, a partir de `Mi-Web-Personal-main.zip`.

Se desarrolló la **propuesta anterior elegida por la usuaria**: negro y naranja, cabecera horizontal, titulares Georgia, presentación amplia con nombre a la izquierda y retrato a la derecha en escritorio. La alternativa con columna lateral no es la composición seleccionada. El análisis previo, el inventario y las dos maquetas se encuentran en [Análisis y propuesta](docs/ANALISIS_Y_PROPUESTA.md).

Este documento separa tres tipos de evidencia: **implementación inspeccionada en el código**, **comprobaciones ejecutadas con resultado registrado** y **pruebas pendientes**. Una mejora implementada no se considera automáticamente validada en navegador. Esta revisión heurística no constituye una prueba con usuarios ni una certificación global de conformidad WCAG.

### Contraste calculado sobre los tokens implementados

Los cálculos usan la fórmula `(L más clara + 0,05) / (L más oscura + 0,05)`, con linealización sRGB. Se comparan colores explícitos de `estilos.css`; no se deducen resultados de una captura ni de una inspección visual informal.

| Uso / par calculado | Colores | Ratio |
| --- | --- | --- |
| Texto principal / fondo oscuro | `#F5F5F5` / `#0D0D0D` | **17,83:1** |
| Acento naranja / fondo oscuro; también texto oscuro sobre botón naranja | `#FF6A00` / `#0D0D0D` | **6,77:1** |
| Texto secundario / panel oscuro | `#C5C5C5` / `#151515` | **10,58:1** |
| Naranja / panel oscuro | `#FF6A00` / `#151515` | **6,36:1** |
| Borde funcional / panel oscuro | `#858585` / `#151515` | **4,95:1** |
| Indicador de foco / fondo oscuro | `#FF8A36` / `#0D0D0D` | **8,27:1** |
| Texto principal / fondo claro | `#191919` / `#FAFAFA` | **16,84:1** |
| Acento naranja oscuro / fondo claro | `#A83B00` / `#FAFAFA` | **6,11:1** |
| Acento naranja oscuro / panel claro | `#A83B00` / `#F0F0F0` | **5,60:1** |
| Texto blanco / botón del tema claro | `#FFFFFF` / `#A83B00` | **6,38:1** |
| Borde funcional / fondo claro | `#747474` / `#FAFAFA` | **4,48:1** |

El tema claro usa **`#A83B00`**, distinto del naranja `#FF6A00` del tema oscuro. El texto de los botones principales también cambia: oscuro sobre naranja en el tema oscuro y blanco sobre naranja oscuro en el tema claro. Las líneas `--line` son separadores decorativos; los campos usan el token específico `--control-border`.

Para interpretar los valores se utilizan [W3C: contraste mínimo de texto](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) y [W3C: contraste no textual](https://www.w3.org/WAI/WCAG22/understanding/non-text-contrast.html). Los pares de texto normal listados superan 4,5:1; los pares funcionales listados superan 3:1. Además, Edge comprobó el contraste básico de texto en ambas variantes de tema a 390 y 1440 px. Esto **no certifica conformidad global** ni cubre todos los componentes, estados, imágenes o criterios aplicables.

## 4. Límites reales y asuntos abiertos

- **El formulario solamente valida.** Lo informa antes de los campos y después de validar; no hay backend, envío, almacenamiento de mensajes ni correo de destino confirmado. El resultado correcto es «Datos válidos. No se ha enviado ningún mensaje».
- **WhatsApp conserva `593999999999`**, tal como consta en la fuente. Su titularidad y funcionamiento no se confirmaron. No se atribuye a Fernanda un número alternativo ni se envían mensajes de prueba.
- **La comprobación externa fue limitada:** la herramienta web recuperó la página del [perfil de GitHub](https://github.com/fernygeek) y el [DOI](https://doi.org/10.13140/RG.2.2.10598.74561) resolvió a una publicación en ResearchGate. LinkedIn y WhatsApp no pudieron recuperarse mediante esa herramienta por errores internos/de caché; esto no demuestra que estén rotos. Su disponibilidad sigue sin confirmar. Recuperar una página no garantiza disponibilidad permanente ni confirma la titularidad de un número. Las URL originales se conservaron y no se enviaron mensajes.
- **No se probó con lector de pantalla.** Los landmarks, etiquetas, nombres accesibles, relaciones ARIA y regiones de estado se inspeccionaron en código; eso no permite afirmar cómo se anunciarán en cada combinación de navegador y tecnología de asistencia.
- **No se realizaron pruebas con personas usuarias ni una auditoría completa de WCAG 2.2.** Los resultados heurísticos, de sintaxis, integridad, contraste e interacción tienen los límites indicados. No se probó zoom real al 200 %, otros navegadores ni equipos móviles físicos. La adaptación de ventanas de Edge no sustituye esas pruebas.
- **La revisión corresponde al sitio local.** No se ha comprobado alojamiento público, configuración de un dominio ni comportamiento de producción.
